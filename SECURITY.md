# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of KotlinImageLoader seriously. If you discover a vulnerability:

1. **Do not open a public issue.**
2. Send an email to `techboostpg@gmail.com` with the subject `[SECURITY] KotlinImageLoader Vulnerability`.
3. Include details, reproduction steps, and impact assessment.
4. You will receive an initial response within 48 hours.
5. Once a patch is confirmed, a security advisory and patched release will be published.
